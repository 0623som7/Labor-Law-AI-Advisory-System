## 复现方式

```bash
DSN="laborlaw:laborlaw_dev@tcp(127.0.0.1:3307)/laborlaw?parseTime=true&charset=utf8mb4&loc=UTC"
export LLM_API_KEY=$(grep -m1 '^LLM_API_KEY=' .env | cut -d= -f2- | tr -d '\r')

go run ./eval -dsn "$DSN" -mode keyword
go run ./eval -dsn "$DSN" -mode semantic
go run ./eval -dsn "$DSN" -mode hybrid
go run ./eval -dsn "$DSN" -mode rerank
```

**四条命令都必须显式带 `-mode`。** 不传时 `eval/main.go:51-58` 会去看 `RETRIEVAL_SEMANTIC` 环境变量：
该变量为真（本机 `.env` 里就是 `on`）时默认跑 `hybrid`，否则跑 `keyword`。
不写 `-mode` 就得出的结果无法说明自己是什么模式，本文件旧版把一次 `hybrid` 结果记成了关键词模式，就是这么来的。

`-semantic` 是 `-mode hybrid` 的旧写法别名（`eval/main.go:46`），新文档一律用 `-mode hybrid`。

## 已知天花板

- **E20（严重违反公司制度被开除，还有经济补偿吗）**：应答 `LCL-39`（过失性辞退无需补偿），
  keyword 档能进 @3，hybrid 档召回 `LCL-46`、rerank 档召回 `LL-28`（都是"一般情形应当补偿"那条）。
  这题本身有歧义——"被开除"既可以指过失性辞退（无补偿），也可以指违法解除（有赔偿金），
  两种读法对应不同条文。不是调权重能解的，需要换判例或问答语料才能让题目本身无歧义。
- **相邻条款的例外/特别规定**（E18、E25 这类）：向量算得出"主题相近"，算不出"这一条正好是例外"。
  rerank 已经把 E18、E25 从 ✗ 捞回 @3，但更大规模的同类问题仍会出现在新增用例里，
  见 `eval/README.md` 的维护约定。

## 2026-11-16 调参后

用 100 条用例做了三个单变量实验，**三个全部回退**，四档基线与上一节一字不差：

| 模式 | hit@3 | hit@5 | 零召回 |
|---|---|---|---|
| keyword | 57/100 57.0% | 70/100 70.0% | 7 |
| semantic | 90/100 90.0% | 94/100 94.0% | 0 |
| hybrid | 81/100 81.0% | 89/100 89.0% | 0 |
| rerank | 94/100 94.0% | 99/100 99.0% | 0 |

复跑（与上一节同一条命令）：

```bash
export DSN='laborlaw:laborlaw_dev@tcp(127.0.0.1:3307)/laborlaw?parseTime=true&charset=utf8mb4&loc=UTC'
for m in keyword semantic hybrid rerank; do echo "=== $m"; go run ./eval -mode $m -dsn "$DSN" | tail -4; done
```

三个实验各一句话（完整前后表、逐条进出、回退理由见 `eval/README.md`「调参实验记录」）：

1. **RRF 两路加权**（关键词 0.5 / 0.3）：hybrid 81.0% → 79.0%、rerank 94.0% → 93.0%，
   回退。降权同时压掉了"关键词独有且正确"的条目，0.5 与 0.3 结果逐条相同。
2. **重排指令中文化**：rerank 94.0% → **95.0%**、`paraphrase` 组 11/12 → 12/12，
   进 E66/E99、掉 E17。协议线是 96.0%，差一条，按协议回退；这是唯一有正收益的一个。
3. **候选池放宽**：`candidateK(3)` 本来就返回 20（不是 12），原实验是空操作；
   改测融合窗口 20 → 30 后 @3 仍是 94.0%，进 E99 掉 E24，p50 188ms → 194ms，回退。

另有一处与数字无关的改动：`eval/main.go` 的目标线 `goal3 = 0.75` **数值没动**，
只是从"所有档都告警"改成"只对 rerank 档告警"，其余三档打印一行
「本档是诊断档（线上走 rerank），目标线 75% 只对 rerank 档适用」。
原来 keyword 档 57.0% 每次跑都刷一行红灯，而 keyword 是诊断档不是生产档。
