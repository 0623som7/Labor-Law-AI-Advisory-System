逐条比对的脚本（两份输出先落文件）：

```bash
go run ./eval -dsn "$DSN"            > /tmp/kw.txt
go run ./eval -dsn "$DSN" -semantic  > /tmp/sem.txt
python - <<'PY'
import re
def parse(p):
    rows = {}
    for line in open(p, encoding='utf-8'):
        m = re.match(r'^(E\d\d)\s+(.*?)\s{2,}(\S+)\s{2,}(\S+)\s{2,}(✓|✗)\s+(✓|✗)\s*$', line.rstrip())
        if m:
            rows[m.group(1)] = (m.group(5) == '✓', m.group(6) == '✓')
    return rows
kw, sem = parse('/tmp/kw.txt'), parse('/tmp/sem.txt')
print('进@3', sorted(k for k in kw if not kw[k][0] and sem[k][0]))
print('进@5', sorted(k for k in kw if not kw[k][1] and sem[k][1]))
print('退化', sorted(k for k in kw if kw[k][0] and not sem[k][0]))
PY
```

## 已知边界

这三条写出来是加分项：知道边界在哪，比声称没有边界可信。

1. **剩余 7 条 miss 集中在"同族的相邻条款"**：系统召回的是这一族的通则，而正确答案是其中的例外或特别规定。
   - E30「兼职有试用期吗」：应答 LCL-70（非全日制不得约定试用期），召回 LCL-19（试用期期限）
   - E20「严重违反公司制度被开除，还有经济补偿吗」：应答 LCL-39（过失性辞退无补偿），召回 LCL-46（一般情形应补偿）
   - E03「试用期工资不得低于多少」：应答 LCL-20，召回 LCL-19
   - E26 / E27 劳务派遣的同工同酬与岗位限制（LCL-63 / LCL-66），都召回 LCL-59（劳务派遣通则）
   - E19「医疗期满被辞退」应答 LCL-40，召回 LCL-46；E24「合同没写岗位和工资」应答 LCL-17/LCL-81，召回 LCL-14

   向量算得出"主题相近"，算不出"这一条正好是例外"。下一步是 rerank（交叉编码器把问题与候选条文成对打分），
   不在本期范围。
2. **OCR 未做。** 扫描件 PDF 抽不出文本层时整份返回 42201，前端提示"这份文件没有文字层，可能是扫描件"，
   不会拿空文本去跑抽取。要支持扫描件需接 OCR（申报书里写的 Tesseract.js 属后续迭代）。
3. **`usage_records` 的日预算闸是进程内的，重启清零。** 单实例部署下可接受；多实例要落 Redis
   （限流与查询向量缓存已经在 Redis 上，只有预算闸还在进程内）。
